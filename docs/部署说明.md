# 部署说明

本项目是纯静态站点，不包含完整真题题库。部署后用户仍可在本机导入获授权获得的 JSON。

## 公开版原则

- GitHub 仓库只包含程序、示例和文档。
- 不要把 `data/real-exams.json` 放进仓库、Release、Actions Artifacts 或公开 CDN。
- 完整题库通过邮箱 **qdgzhtao@163.com** 申请，审核后手动发送。
- 使用者收到 JSON 后，在「题库 → 导入题库」中导入；题库只保存在本机 `localStorage`。

## 方式 A：Netlify

1. 在 Netlify 连接 GitHub 仓库。
2. Build command 留空。
3. Publish directory 填 `.`。
4. 部署后得到 HTTPS 地址。

## 方式 B：Cloudflare Pages

1. Cloudflare Dashboard → Workers & Pages → Create → Pages。
2. 连接 GitHub 仓库。
3. Build command 留空，输出目录填 `.`。
4. `_headers` 会自动应用基础安全响应头。

## 方式 C：Vercel

1. 在 Vercel 导入 GitHub 仓库。
2. Framework 选择 Other。
3. Build Command 留空，Output Directory 填 `.`。
4. `vercel.json` 已包含基础响应头配置。

## 方式 D：GitHub Pages

1. 仓库 Settings → Pages。
2. Source 选择 Deploy from a branch。
3. 选择 `main` 分支和根目录。
4. 得到 `https://用户名.github.io/仓库名/`。

## 部署后的使用

1. 手机打开 HTTPS 地址。
2. 浏览器菜单 → 添加到主屏幕，可启用 PWA。
3. 收到完整题库后，通过「题库 → 导入题库」导入本机。
4. 如需跨设备同步进度，按 `docs/云同步配置.md` 配置 Supabase。

## 本地开发

```bash
python -m http.server 8080
```

打开 <http://localhost:8080>。PWA/Service Worker 需要 HTTPS 或 localhost。
