# 云同步配置（Supabase，可选）

> 目标：电脑和手机各自本地保存，联网时通过同一个“同步码”合并进度；断网时照常做题。  
> 同步内容：做题进度、生词本、设置、本地记忆。题库默认不同步，避免每次上传约 1.9MB 的真题文件。

## 1. 创建 Supabase 项目

1. 打开 <https://supabase.com/>，注册/登录。
2. 新建一个项目（免费额度足够个人使用）。
3. 等待项目初始化完成。

## 2. 建表和 RPC 函数

1. 进入 Supabase 项目 → **SQL Editor**。
2. 打开本项目的 `supabase/schema.sql`，整段复制到 SQL Editor。
3. 点击 **Run**，确认没有报错。

这个脚本会创建：

- `public.kaoyan_sync` 表；
- `kaoyan_sync_get(p_code)` 读取函数；
- `kaoyan_sync_put(p_code, p_payload)` 写入函数；
- 只允许 `anon` 通过 RPC 访问，直接读表会被 RLS 拒绝。

## 3. 获取 URL 和 Anon Key

在 Supabase 项目 → **Settings → API** 中找到：

- **Project URL**：形如 `https://xxxx.supabase.co`
- **anon public key**：很长的 `eyJ...` 字符串

不要把 `service_role` key 填进应用；只需要 anon key。

## 4. 在应用里配置

电脑打开应用 → **设置 → 云同步（可选）**：

1. 填入 Supabase URL 和 Anon Key。
2. 点「生成」得到同步码；同步码相当于密码，请勿公开。
3. 建议开启「自动同步」。
4. 点「智能同步」。
   - 云端没有数据时：自动上传本机快照。
   - 云端已有数据时：按每条进度/生词的更新时间合并。
5. 看到「已连接 · 上次 …」即成功。

## 5. 第二台设备

在手机（或另一台电脑）打开同一个应用，进入设置 → 云同步：

1. 填入**同一个** Supabase URL、Anon Key。
2. 填入**同一个**同步码。
3. 开启自动同步，点「智能同步」。

之后两台设备联网时会自动合并进度。断网时仍然只写本机，联网后再同步。

## 6. 同步策略

- **进度**：同一篇取 `updatedAt` 较新的记录；同时间优先已提交记录。
- **生词本**：按单词合并，取更新时间较新/次数较多的记录。
- **本地记忆**：取最近访问较新的记忆；进站次数取两边最大值。
- **设置**：智能同步以本机设置为准。
- **题库**：默认不同步；勾选「同时同步题库」后才会合并题库（约 1.9MB，建议按需开启）。

## 7. 安全说明

- 同步码是唯一访问凭证，请使用「生成」按钮产生的长随机码，不要用 `123456`。
- Anon Key 本身是公开客户端 key；真正的隔离靠 RPC + 同步码。
- Supabase 项目管理员可以看到数据库内容；这不是端到端加密。
- 不要把 Supabase `service_role` key 写进前端。
- 「清空全部数据」会同时清除本机的云同步配置（云端快照不会自动删除）。

## 8. 常见问题

| 现象 | 处理 |
|---|---|
| `HTTP 404` | `supabase/schema.sql` 没执行，或函数名不是 `kaoyan_sync_get/put` |
| `HTTP 401/403` | Anon Key 填错，或没有执行 grant 语句 |
| 同步一直失败 | 检查网络、Supabase 项目是否暂停、URL 是否以 `https://` 开头 |
| 手机和电脑不互通 | 确认 URL、Anon Key、同步码三者在两端完全一致 |
| 题库没有同步 | 默认不同步题库；在设置里勾选「同时同步题库」后再智能同步 |

## 9. 免费额度说明

Supabase 免费项目长期不活跃可能会被暂停；重新打开项目即可恢复。个人学习用途通常够用。
