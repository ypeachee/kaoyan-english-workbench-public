# 考研英语工作台

一个**单页、静态、本地优先**的考研英语练习工作台：阅读练习、逐题解析、长按/双击查词、生词本、错题本、统计、本地记忆、JSON 导入导出、可选云同步与 PWA 离线。

> **公开仓库不包含完整真题题库。**  
> 完整题库不在 GitHub 仓库、Releases、Actions Artifacts 或公开站点中。需要题库请发送邮件申请，审核后手动发送 JSON，再由使用者导入本机。

## 1. 已实现功能

| 模块 | 能力 |

## 2. 题库为什么单独申请

完整题库包含第三方考试内容，不适合直接放入公开仓库：

- 公开 Git 历史会保留曾经提交过的文件；
- GitHub Release 附件和 Actions Artifacts 同样是公开的；
- 把 JSON 放进前端代码、分支或 CDN 都等于公开分发。

因此本项目采用：

1. 公开仓库只放程序、示例和文档；
2. 完整题库由维护者通过邮件审核后私发；
3. 使用者通过「题库 → 导入题库」把 JSON 导入本机；
4. 题库只保存在该设备的 `localStorage` 中；
5. 已授权内容仍可能被二次转发，因此这是申请制，不是 DRM。

## 3. 本地运行

### 方式一：直接打开

双击 `index.html`。示例练习和本地存储可用，但 Service Worker/PWA 不生效。

### 方式二：本地 HTTP 服务（推荐）

```bash
python -m http.server 8080
```

浏览器打开 <http://localhost:8080>。

---

## 4. 导入完整题库

收到 `real-exams.json` 后：

1. 打开「题库」；
2. 点击「导入题库」；
3. 选择 JSON 文件，或把 JSON 粘贴到文本框；
4. 点击「导入并保存」。

支持的格式：

```json
{ "papers": [ { "id": "y2013-t3", "passage": "...", "questions": [] } ] }
```

也支持单篇 paper 对象，以及包含 `bank`、`progress`、`vocab`、`memory` 的完整备份。

## 7. 隐私与数据

- 学习进度默认保存在浏览器 `localStorage`。
- 在线查词只发送当前单词到 MyMemory。
- 邮件申请和反馈通过本机邮件客户端发送。
- 清除浏览器站点数据会同时清空本地进度，请定期导出备份。
- Supabase 云同步为可选功能，需要使用者自行创建项目并填写配置。

---

## 8. CI 检查

GitHub Actions 会检查：

- `app.js` 是否通过 JavaScript 语法检查；
- 公开示例是否可读取；
- `data/real-exams.json` 是否被误提交；
- 仓库中是否出现异常大的 JSON 题库文件。

任何一步失败都会阻止公开代码仓库误带完整题库。

## 10. 设计取舍

- **单页 + 原生 JS**：零构建、低依赖，任何静态托管都能运行。
- **本地优先**：断网可用，不把学习记录默认交给第三方。
- **计划与题库分离**：公开项目可独立运行，完整题库按需导入。
- **查词本地优先**：内置词库 + 在线兜底，只发送单个单词。
- **公开代码、受控分发内容**：兼顾项目可协作与第三方内容边界。
